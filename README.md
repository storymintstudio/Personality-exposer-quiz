# The Personality Exposer 

An interactive personality quiz website by **Storymint Studio** that reveals your personality through 3 fun questions.

### Features
- Interactive multiple-choice quiz
- Four unique personality results
- Smooth animations and transitions
- Shareable result cards
- Replay and responsive design

### Tech Stack
HTML • CSS • JavaScript

### Goal
Create a fun, engaging experience that encourages users to share their results with friends.
